This directory is the source repository for the user's Windows and macOS personal workbench.
Remote: https://github.com/AlexShen-Oguri/-DailyHouse.git, branch main.

- The owner authorized private multi-device synchronization and only necessary Codex / Claude Code integration. - The initial commit records the user-approved baseline. Preserve its history.

- Do not commit personal data, account credentials, reports, local notes, browser state, screenshots, logs, generated build output, or .runtime backups. Keep them excluded by .gitignore.
- Follow [SECURITY.md](SECURITY.md) and [the Development Security Standard](docs/development-security.md) for all future work. Keep local storage as the default; optional private cloud must use explicit upload scope, verified access controls and revocable device pairing. Open-source users must use their own local or independent cloud storage, not the developer's personal backend. Public multi-user hosting requires a separate owner decision. These standards do not authorize implementation of proposed cloud features.
