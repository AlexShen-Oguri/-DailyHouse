# 书架：分类、导入批次与回收站

## 页面组织

书架把主要操作分开：顶层「未完成」「已完成」决定正在处理还是回看资料；紧凑类型入口决定看书籍、视频、课程教程、GitHub、文章还是两种日报。主题分类另列为筛选，避免把媒介类型、主题和完成状态混成同一组。

标记完成后保留打勾与淡出，记录完成时间；内容仍保存在同一条记录中，可以重新开始、编辑和移除。封面和笔记保留，页面刷新不重置状态。旧记录若没有可靠的完成时间，不推算历史日期。

## 视频候选规则

- 最近 7 × 24 小时的观看记录；时间必须有明确时区。窗口在提交时重新核验。
- 已知播放位置严格低于 25%；未知不能当成 0，多 P 当前分集位置不等于整门课程进度。
- 范围扩大到教育和实用内容：编程、AI、设计、科学、人文、语言、职业/效率、生活技能及其他。
- 明显的纯娱乐内容排除；主题不明确的条目留在预览待确认。用户可主动接收待确认项、取消本次候选，导入后仍可修改分类。
- 自动分类采用本地标题规则，有可见理由；不是模型已观看视频或读完字幕。手动改过的分类不会被再次导入覆盖。

B站采集仍来自已授权的登录浏览器页面。本网站和下面的 CLI 负责接收、校验、分类、去重和保存，不读取浏览器 cookie，也不声称拥有可靠的官方历史接口。尚未建立新的后台定时任务。登录失效或页面没读完整时必须记录不完整覆盖，不能报告整个星期已经同步成功。

## 输入与命令

已实现命令使用 Node.js，运行时本机工作台须已启动。默认端口 3456，`--port` 仅可更改本机端口；不能指定外部服务器。

```powershell
node scripts/reading-import.mjs preview .runtime/history.local.json
node scripts/reading-import.mjs apply .runtime/history.local.json
node scripts/reading-import.mjs history
node scripts/reading-import.mjs undo <导入批次ID>
```

`preview` 不导入。`apply` 先请求预览校验，再提交相同输入，由服务端重新判断最新的重复、抑制和时间窗口；同时有人编辑或删除也不能被旧预览覆盖。所有写入经过 API，不直接改个人 JSON。输入文件、预览输出和浏览器记录放在被 Git 忽略的本机目录。

输入示意（链接和日期仅用于说明结构，使用时必须换成实际页面证据）：

```json
{
  "items": [
    {
      "title": "示例：摄影构图入门教程",
      "url": "https://www.bilibili.com/video/BV1234567890/",
      "viewedAt": "2026-09-27T09:00:00-04:00",
      "progress": 0.12,
      "notes": "来源页面显示 01:12 / 10:00；只代表这一分集的位置。"
    }
  ],
  "coverage": {
    "from": "2026-09-20T09:00:00-04:00",
    "to": "2026-09-27T09:00:00-04:00",
    "complete": true
  }
}
```

`progress` 是 0–1 的比例，不是 0–100 的百分数；`null` 表示未知。已有可见图片地址可通过 `coverUrl` 提供，仅接受受支持的 HTTPS B站图片来源。`acceptedUrls` 可显式接收主题待确认项，`excludedUrls` 可从本批排除条目；这些选择不能绕过时间、播放位置、明显娱乐、重复与删除抑制规则。

## 去重、移除与恢复

同一 B站 BV 视频只保留一份，分集信息作为观看证据保留；普通链接使用规范来源身份。导入先检查当前书架，再检查被移除来源，因此已完成内容不会被重新排入待读，删除的内容也不会在下一次导入中复活。

单项、多选和全部移除都进入书架回收站，保留原 ID、阅读状态、分类、笔记、封面和完成时间；回收站可单项或批量恢复，整批恢复原子完成。全部移除仍针对确认时列出的 ID 快照，不影响确认后才出现的新条目。移除日报只隐藏本地入口，不删除 PDF。

30 天内可恢复；到期后不可恢复完整快照，后续操作会清理过期正文，保留最小来源抑制信息，防止再次自动导入。没有永久删除按钮。显式手动「收进书架」可以重新收藏一个旧来源并清除其抑制，但这是新记录；保留原 ID 和笔记应使用恢复。若同一来源已被重新手动收藏，恢复旧记录会提示冲突，避免重复或覆盖。

此前版本永久移除的内容没有回收站快照，不假装可以找回。已知的历史删除来源可登记为抑制记录；不会用旧备份还原整个数据库。书架移除不影响现有今日待办，也不删除原始视频或文件。

## 导入管理

每批记录时间、覆盖范围、分类理由及新增/重复/抑制/排除/待确认数量。用户可以查看批次并撤销：撤销只移除该批新建、之后未被用户改动的条目，并放入回收站。后来写过笔记、完成、改变分类或恢复过的条目保留，显示冲突数量；补封面不算用户改动。重复撤销不会再次删除内容。

网络或输入错误保留原数据；重新预览后可重试。批次撤销不会关闭网页、取消 B站收藏或删除任何源视频。新自动调度和其他来源连接仍按 [日常自动化方案](daily-automation-proposal.md) 分阶段接入。
