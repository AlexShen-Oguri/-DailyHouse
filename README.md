# 日常小院 · Windows 个人工作台

按个人需求重构的本地工作台。沿用原创像素田园界面，加入木纹、纸纹、园丁与盆栽。当前入口只有我的小院、今日待办、知识书屋、收支账本和小院设置。

## 打开与关闭

双击桌面 **日常小院** 图标，或 **启动日常小院.cmd**，打开 http://127.0.0.1:3456/ 。后台启动后可以关闭命令行窗口；重复启动不会重复创建服务。停止时双击项目中的 Stop.cmd，或上一级的停止个人工作台.cmd。

Windows 的 CMD 使用系统文件类型图标，因此另提供同名风格的快捷方式图标。桌面两个入口启动同一个程序。

## 已实现

- **待办**：手动添加、日期、完成/恢复、删除；桌面文件按需加入待办。
- **桌面读取**：手动读取桌面及两层子目录的文件名、类型、大小和修改时间；不读取正文、不移动文件。最多 500 项。
- **Obsidian 书屋**：连接已有本机仓库，按标题/路径搜索 Markdown、阅读基础排版与代码、跳转双链、在 Obsidian 打开。相对路径按当前笔记目录解析；不静默选取有歧义的同名笔记。最多列出 5000 篇，预览文件限 1 MB；复杂嵌入和插件效果在 Obsidian 中查看。
- **Apple Calendar**：读取已有 iCloud HTTPS/webcal 订阅或从 Apple Calendar 导出的本机 .ics 文件；支持重复、例外、改期、全天、时区和夏令时，显示今天起 31 天的日程。日历只读，文件模式是快照，需要更新文件后再读取。
- **Chase 账本**：已替换旧财务功能，当前只保留 Chase 接入入口。尚未拿到可供本应用使用的已有连接，未读取真实余额或交易。
- **小院动态**：首页暂停按钮、设置总开关、系统减少动态、离屏与后台暂停。

Obsidian 仓库路径、Apple Calendar 来源、Chase 原绑定服务目前还待用户确认。配置入口在小院设置；这里没有 Apple ID 或银行密码输入框。

## 已移除

内容表现、热点雷达、文件整理、小红书相关功能、Things、飞书、AI 规划与其他冗余连接器、旧后台调度器已从运行代码中移除。未按照侧写自动添加任何新功能。

原源码、配置及脚本在 .runtime/legacy 中保留，旧 SQLite 数据文件仍留在 backend/data；它们不会被新版加载。

## 数据与安装

- 服务只监听本机 127.0.0.1。
- 新待办和来源配置：backend/data/personal-workbench.json（首次保存时创建）。
- 订阅链接只保存在本机配置中，公共 API 不返回链接。连接后仅向用户指定的 iCloud 地址读取日历。
- 备份前停止服务，复制 backend/data 和 backend/.env.local。Obsidian 笔记留在原仓库。
- 环境：Node.js 24；项目 Install.cmd 安装依赖并构建，Start.cmd 启动，Stop.cmd 停止。需要重装时先停止服务；不再依赖 SQLite 原生编译。
- 重建桌面入口：运行 scripts/Install-DesktopShortcut.ps1。
- 启动日志：.runtime/backend.stderr.log。
